# Run 2: what changed and why

Run 2 started from the branch `claude/israeli-coalition-statement-zz7csh` (run 1). It treated run 1 as a draft to challenge.

## 1. Process

| | Run 1 | Run 2 |
|---|---|---|
| Agent instruction | "Supportive of a middle ground" | Argue as the party's real negotiators, rivals and voters would. Accept only gains clearly larger than concessions by the party's own worldview. "No deal" is a legitimate result. (`research/BRIEF_v2.md`, `reviews/run2/ROUND_BRIEF.md`) |
| Research | One pass, partly from search summaries | Nine independent agents in Hebrew, Arabic and English. Each run-1 dossier verified claim by claim, with a verification log in section 0 of every `research/<slug>.md`. |
| Facts | Seat count assumed | `research/RESULTS_2026.md`: preliminary results at about 90%, bloc arithmetic, election-night quotes, procedure |
| Style | Coordinator's own translation | `research/STYLE_GUIDE.md`: verbatim models from the 2021 Ra'am and Yamina agreements, the 2022 agreements, basic guidelines and Arab-Israeli party statements, plus 50 concrete edits. Native drafter passes (`drafts/he_drafting_notes.md`, `drafts/ar_drafting_notes.md`), a blind back-translation check (`drafts/verification_report.md`) and a party wording check (`reviews/run2/lock_check/`). |
| Rounds | 4 review rounds, converging to nine signatures | 3 negotiation rounds (`drafts/statement_v4.md` to `v6.md`, `reviews/run2/round_1–3/`), ending in an impasse on the government and agreement on three bills |

## 3. Drafting (all three languages)
- **Hebrew.** Rewritten in coalition-agreement register:
  - a הואיל chain; "תוקם ממשלה בראשות ח"כ…";
  - bare topic headings; sub-items א.–ד.;
  - no bold inside clauses; almost no em dashes;
  - "יוכנס לבסיס התקציב" for budget protection;
  - correct statute names, for example תיקון 116 לחוק התכנון והבנייה and חוק שירות ביטחון [נוסח משולב], התשמ"ו–1986;
  - calques removed: מתעדת, חירותו לפעול, בערכים ריאליים, ידעה כאב.
- **Arabic.** Rewritten in the register Adalah and Arab48 use:
  - «ستعمل الحكومة على», «حيث إنّ… لذلك اتُّفق»;
  - the community's terms: خرائط هيكلية، اللجنة القطرية، قانون كامينيتس (التعديل 116);
  - «لجنة مراقبة التنفيذ» rather than «لجنة المتابعة», which would have read as the High Follow-Up Committee;
  - each Arab faction's reply in its own voice.
- **English.** Plain drafting with varied clause length, rather than symmetrical triplets and explanatory asides.
- **TV texts.** Short spoken sentences, with each speaker's register kept: Abbas's colloquial punchline, and the Joint List's «يا أبناء شعبنا».
- **Locked wording.** Each party's terms were collected in round 3 and checked against the native texts afterwards. Run-2 examples:
  - Hebrew: טרור יהודי, קומץ אלים, יהודה ושומרון (הגדה המערבית), הר הבית (אל-אקצא), חטופים;
  - Arabic: الضفة الغربية first, «الإرهاب اليهودي», «المسجد الأقصى المبارك / الحرم القدسي الشريف», «المواطنون العرب في إسرائيل».
- **Two meaning-level fixes made during drafting:**
  - "the Minister of Public Security" became "the minister responsible for the police". The portfolio has been called National Security since 2022, so the old name would be wrong.
  - "in the Gaza Strip as elsewhere" became "including in the Gaza Strip", restoring the run-1 wording that Hadash and Ta'al accepted.

## 4. PDF
- `final/build_pdf.py` now renders a status cover and one page per TV statement, with the original first and the other two languages beside it.
- It then renders the framework in each language and one signature page per tier, on which Bennett and Lieberman are shown as **declined**.
- The fonts are Noto Sans, Noto Sans Hebrew and Noto Naskh Arabic woff2 files from `@fontsource` on jsdelivr.
- To build: `python3 final/build_pdf.py <fonts_dir>`.

*Simulation exercise. It does not speak for any party.*
